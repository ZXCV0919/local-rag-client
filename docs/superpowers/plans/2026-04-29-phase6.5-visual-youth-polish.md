# 阶段 6.5：年轻向视觉与交互打磨 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不大改架构的前提下，强化产品视觉人格与信息架构：深色侧栏 + 浅色工作区、聊天经典布局（居中消息流 + 底栏输入）、导航去重、引用来源可感知；并统一 token、卡片、空状态与动效。不改变 RAG / 检索 / 会话等业务逻辑。

**Architecture:** 以 CSS 设计 token（`variables.css`、`global.css`）为单一事实来源，组件层用 Tailwind 类消费 `var(--*)`。主题色沿用现有 `applyAccentVariables` 与设置持久化。动画遵守 `prefers-reduced-motion`。

**Tech Stack:** Tailwind CSS v4、现有 Radix/React 组件、Plus Jakarta Sans（`index.html` 外链）。

**边界（与阶段 7 区分）：** 本阶段不涉及 Ollama 管理深化、性能剖析；Command Palette 列为可选后续。若需新增 settings 字段保持最小改动。

**设计参考：** `assets/ui-preview-01-chat-interface.png`、`ui-preview-02-knowledge-base-dashboard.png`、`ui-preview-03-document-management.png`
