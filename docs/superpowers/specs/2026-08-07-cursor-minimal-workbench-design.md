# 本地知识库 · Cursor 式极简三栏工作台设计

**日期：** 2026-08-07  
**状态：** 已确认方向（用户认可）  
**前置：** 墨书工作台视觉迭代；本规格升级为产品级信息架构重做  
**美学：** 极简、少色彩（参考 Cursor：浅灰/白、细线、弱强调色）

---

## 1. 目标

把应用做成「IDE 式知识工作台」，而不是后台管理页：

- 左：知识库 + 库内对话
- 中：对话主舞台
- 右：库内文档树 + 文件内容预览（**默认关闭**，顶栏一键开关）
- 输入区：本地 / 云端切换；云端可选模型

成功标准：打开应用第一眼像专业桌面产品；关闭右栏后主路径只有「选库 → 对话」。

---

## 2. 信息架构

```
┌─ Titlebar: Brand · 当前库/会话名 ··············· [资料面板] ─┐
├────────────────┬────────────────────────────┬────────────────┤
│ 左栏（常驻）    │ 中栏（主舞台）               │ 右栏（默认关）  │
│                │                            │                │
│ 知识库列表     │  消息流                     │ 文档树         │
│  └ 当前库会话  │  输入区                     │  └ 文件预览    │
│                │   [本地|云端] [模型▾]        │                │
│ ─────────────  │                            │                │
│ 设置           │                            │                │
└────────────────┴────────────────────────────┴────────────────┘
```

### 2.1 左栏

- 顶部：产品名（小字即可，不抢戏）
- **知识库**：可折叠分组；选中库后，其下展示该库会话列表（标题 + 相对时间）
- 操作：新建对话、新建知识库（克制入口）
- 底部：设置
- 点击库：**直接进入该库对话**（最近会话或空会话占位），不再默认厚概览
- 概览 / 文档管理：降为次要入口（会话旁菜单或设置旁），不占主导航

### 2.2 中栏

- 仅对话：消息列表 + 底部输入
- 无常驻检索工作台；「排查检索」收在溢出菜单或次要图标
- 输入区控件（对齐 Cursor 输入条气质）：
  - **本地 | 云端** 切换（绑定现有 `chat_provider`：ollama / siliconflow）
  - **云端时**：模型下拉（SiliconFlow 预设 + 自定义，复用现有设置数据）
  - 本地时：可显示当前 Ollama chat 模型名（只读或轻量选择，若成本高则只读）

### 2.3 右栏（资料面板）

- **默认关闭**
- 顶栏按钮切换；`localStorage` 记住开关（键名如 `ui.sourcesPanelOpen`）
- 打开后建议两段：
  1. 当前库文档列表（树或扁平列表）
  2. 选中文档的内容/分块预览（复用现有文档详情/分块预览能力，可简化）
- 从引用 pill「查看原文」：可自动打开右栏并定位到对应文档/片段

### 2.4 路由建议

| 行为 | 路由 |
|------|------|
| 选库 | `/kb/:id/chat`（有最近会话则进该会话，否则占位） |
| 选会话 | `/kb/:id/chat/:conversationId` |
| 设置 | `/settings`（全宽或中栏替换，左栏可保留） |
| 旧概览 `/kb/:id` | 重定向到 chat，或保留为次要「库详情」页 |

## 3. 视觉系统（极简）

相对墨书「暖纸感 + 重青绿」，本规格改为 **Cursor 近邻极简**：

| Token | 浅色建议 |
|-------|----------|
| 主底 | `#f7f7f8` |
| 表面 | `#ffffff` |
| 侧栏 | `#f3f3f4` 或略深于主底（**浅侧栏**，非深石板） |
| 边框 | `#e5e5e5` / `#ebebeb` |
| 主文字 | `#1a1a1a` |
| 次文字 | `#6b6b6b` |
| 强调色 | 保留单一 accent（默认青绿或中性黑按钮），**大面积不用彩色装饰** |
| 阴影 | 极少；靠边框与背景差分层 |

原则：

- 不要渐变光晕、不要 hero 彩条、不要多色徽章堆砌
- 选中态：浅灰底 + 细左边线或字重，而非高饱和色块
- 字体：保持现有 sans；字号克制、密度接近 IDE

深色主题：对齐同一极简逻辑（深灰层级，非青绿氛围光）。

## 4. 组件拆分（实现指引）

| 单元 | 职责 |
|------|------|
| `WorkbenchShell` | 三栏骨架 + 右栏开关状态 |
| `KbConversationSidebar` | 库列表 + 嵌套会话 |
| `ChatStage` | 中栏消息 + 输入 |
| `ComposerBar` | 本地/云端 + 模型选择 + 发送 |
| `SourcesPanel` | 文档树 + 预览；可卸载 |
| `Titlebar` | Brand + 面板开关 |

数据：继续用现有 `list_knowledge_bases` / `list_conversations` / `list_documents` / settings；不新开后端子系统。

---

## 5. 非目标

- 不复制 Cursor 的 Automations / Slack / Agent 模式
- 不重写 RAG / 检索算法
- 本轮不做行级溯源（可另立阶段；右栏预览可为后续溯源载体）
- 不做多色彩品牌插画

## 7. 验收

- [ ] 左栏可见「库 → 会话」层级，像 Cursor Repositories
- [ ] 中栏是干净对话；输入区有本地/云端；云端有模型选择
- [ ] 右栏默认关闭；顶栏一键开/关；打开后能浏览库内文档并预览
- [ ] 整体少彩、浅灰白极简，无明显装饰渐变
- [ ] 选库默认进入对话，而非厚概览仪表盘
