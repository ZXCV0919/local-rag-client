# 本地知识库 · 墨书工作台界面重做设计

**日期：** 2026-08-07  
**状态：** 已确认方向，待实现计划  
**范围：** 仅界面与信息架构（产品级 B 档）；行级溯源另立阶段  
**产品名：** 本地知识库（不改名，品牌靠 mark + chrome）

---

## 1. 背景与目标

### 老师反馈（界面部分）

> 界面好好做做吧，你这个太简陋了，布局样式问题很大。

### 现状结论

- Phase 10 已换青绿令牌、空状态、健康条、演示语料，但整体仍像扁平管理后台。
- 品牌弱（空 Titlebar、Vite favicon）、层次弱（全白）、概览过薄、对话页像检索实验室。
- 截图资产缺失，README 无法视觉证明质量。

### 成功标准（老师演示）

1. 打开应用即有独立产品壳，不像空 Tauri / Vite 模板。
2. 进入知识库先看到「厚概览」，状态一眼可读，一键进对话。
3. 对话页是干净阅读体验；检索诊断不常驻。
4. 库列表 / 概览 / 对话三屏视觉统一，有品牌 mark。
5. README 具备 3 张真实截图。

### 非目标（本阶段）

- 行级溯源 / 引用精确到行（下阶段）
- 重写 RAG、换向量库、改默认检索算法
- 紫靛蓝 SaaS 风或暖奶油+赤陶风换皮
- 为改 UI 而大规模拆后端 API

## 3. 信息架构

### 3.1 全局壳

```
┌─────────────────────────────────────────────────────────┐
│ Titlebar: [Mark] 本地知识库                    [_][□][X] │
├──────────┬──────────────────────────────────────────────┤
│ 深色侧栏  │  （可选）DependencyHealthBanner 细条可关      │
│ Mark+名  │──────────────────────────────────────────────│
│ 知识库列表 │  主内容区（纸感底）                           │
│ …        │                                              │
│ 设置     │                                              │
└──────────┴──────────────────────────────────────────────┘
```

- 侧栏底色：深石板 `#1c2422`；主区：纸感浅底 `#f7f6f3` + 表面 `#fffcf8`。
- 健康条保留，视觉权重低于品牌区；支持**当前会话内关闭**（不写进永久设置也可接受）。

### 3.2 知识库内导航

进入某知识库后，主区顶栏三段：**概览 | 文档 | 对话**（当前项强调）。

| 路由（可保留现有 path） | 角色 |
|------------------------|------|
| `/kb/:id` | 默认落点：厚概览 |
| `/kb/:id/documents` | 文档导入与管理 |
| `/kb/:id/chat` | 对话（产品主路径） |
| `/documents/:id` | 文档详情 / 分块预览（从引用或文档卡进入） |
| `/settings` | 设置 |

侧栏点击知识库 → 概览，不直接进对话。

### 3.3 排查检索

- 入口：对话页标题栏次要按钮「排查检索」。
- 形态：右侧抽屉（可调宽），内嵌现有检索模式与命中列表。
- 默认：关闭。关闭后对话区恢复为单一阅读构图。

## 4. 视觉系统

### 4.1 色彩

| Token 角色 | 浅色值（示意） |
|------------|----------------|
| Accent | `#0f766e` |
| Accent hover | `#0d9488` |
| On accent | `#ffffff` |
| Bg primary | `#f7f6f3` |
| Bg secondary | `#efece6` |
| Surface | `#fffcf8` |
| Sidebar bg | `#1c2422` |
| Sidebar text | `#e8e6e1`（次级 `#a8b0ad`） |
| Border | `#e7e2d9` |

- 引用高亮 / citation pill 使用 accent 的 alpha，不写死旧靛蓝。
- `--gradient-page` 可在主区轻量启用（极淡），禁止装饰性大光晕。

### 4.2 字体与字号

- UI / 品牌拉丁：Plus Jakarta Sans；中文用清晰系统栈（微软雅黑 / Segoe UI 等），不以 Inter 当主脸。
- 正文 14–15px；标题走 CSS 令牌阶梯。
- 禁止页面内随意 `text-[9px]` / `text-[10px]`；徽章与 pill 统一 12px。

### 4.3 圆角与控件

- 控件 `8px`，卡片 / 弹层 `12px`。
- 主按钮实心青绿；次按钮描边；危险操作红色。
- 阴影最多 1～2 级轻阴影。

### 4.4 Brand mark

- 几何「书页折角」图标，青绿底。
- 用于：Titlebar、侧栏品牌区、favicon、安装包图标（去掉 Vite 默认标）。

## 5. 关键屏规格

### 5.1 知识库列表 `/`

- 页标题「我的知识库」+「新建」主按钮。
- 卡片：顶色条（`kb-theme`）+ 名称 +「N 文档 · 状态」；禁止千篇一律灰文件夹。
- 空状态：mark +「创建第一个知识库」+ 次要「导入演示语料」。

### 5.2 厚概览 `/kb/:id`（进库默认）

必须包含：

1. 知识库标题与简短描述（若有）
2. 三统计：文档数 / 分块数 / 就绪状态
3. **最近对话**列表（可点击继续）
4. **文档动态**：就绪 / 处理中 / 失败摘要
5. 主 CTA：**开始提问** → 对话页
6. 次 CTA：导入文档 / 管理文档

不再只是「标题 + 三个数字 + 三个按钮」的空白页。

### 5.3 对话 `/kb/:id/chat`

```
[侧栏] [会话细栏] [居中阅读栏 max-width: 720px]     [排查抽屉 · 默认关]
                    消息 + 引用 pill
                    输入框贴底居中
```

- 用户气泡：accent；助手：surface + 边框。
- 引用 pill：青绿半透明；点击 → 现有 popover / 查看原文（行级增强属下阶段）。
- 空对话：三步引导（导入 → 等就绪 → 提问）。

### 5.4 文档列表

- 显眼拖放导入区 + 格式说明。
- 文档卡状态可视化（就绪 / 处理中 / 失败）。
- 空状态与导入 CTA 清晰。

### 5.5 设置

- 保持现有分区；控件圆角 / 字号对齐新令牌；外观预设以青绿 / 石板 / 琥珀为前序。

## 6. 动效

仅保留有目的的 2～3 处：

1. 知识库切换：主区内容短淡入（150–200ms）
2. 新消息：自下而上短淡入
3. 卡片 / 主按钮 hover：轻抬升或边框强调（无 glow）

遵守 `prefers-reduced-motion`。

## 8. 错误与降级

- 概览数据加载失败：分区级错误提示 + 重试，不整页白屏。
- 健康条告警时不阻断进入概览 / 对话；文案指向设置。
- 排查抽屉打开失败：toast，不影响主对话。
