# 运维排障（Ollama / ChromaDB）

面向本机开发与演示。若设置页显示离线或导入失败，按下列条目排查。

## 1. Ollama 未连接

**现象：** 设置 → Ollama 红点 /「离线」；导入卡在向量化；问答提示检查 Ollama。

**原因：** 服务未启动，或端口不是默认 `11434`。

**处理：**

1. 启动 Ollama 桌面端或执行 `ollama serve`
2. 浏览器打开 `http://127.0.0.1:11434` 应有响应
3. 回到应用点击「检测连接」

## 2. 嵌入模型未拉取

**现象：** 文档长期「处理中」或状态 error，日志/错误信息含 embed / model not found。

**原因：** 未安装默认嵌入模型 `nomic-embed-text`（或设置里改了模型名但未 pull）。

**处理：**

```bash
ollama pull nomic-embed-text
```

对话模型（如 `qwen2.5:7b`）按需：

```bash
ollama pull qwen2.5:7b
```

## 3. ChromaDB 未响应

**现象：** 数据管理里 Chroma「未响应」；检索/导入失败。

**原因：** 进程未起、端口占用，或本机未安装可用的 Chroma CLI/Python 包。

**处理：**

1. 在设置 → 数据管理点击「启动」后「刷新状态」
2. 确认本机可运行 `chromadb` / 相关服务
3. 检查防火墙是否拦截本地回环端口
4. 仍失败时查看该页展示的 `last_error` 原文

## 4. 文档已导入但问答答不上 / 总拒答

**现象：** 有文档，但总是「库内无可靠依据」。

**原因：** 文档未到「就绪」；检索模式与问题不匹配；问题与库内容无关（门控正常）。

**处理：**

1. 文档管理确认状态为「就绪」
2. 用文档里的原词提问，或切换检索模式（语义 / 关键词 / 智能）
3. 打开检索工作台查看是否召回到相关片段

## 5. SiliconFlow 无法生成

**现象：** 提供方已选 SiliconFlow，但报错或空响应。

**原因：** API Key / Base URL 错误，或网络不可达；嵌入仍依赖本机 Ollama。

**处理：**

1. 设置中重新填写 Key 并「测试连接」
2. 确认 Ollama 嵌入仍可用（检索依赖本地嵌入）
3. 检查代理/公司网络是否拦截 `api.siliconflow.cn`
