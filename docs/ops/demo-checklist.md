# 演示前 Checklist（约 1–2 分钟）

用于秋招 / 答辩演示，避免环境翻车。

## 启动前

- [ ] Ollama 已运行（设置页绿点）
- [ ] 已拉取 `nomic-embed-text`；对话模型已拉取（若演示本地生成）
- [ ] ChromaDB 心跳正常（设置 → 数据管理）
- [ ] 准备好 1 个小知识库 + ≥1 份「就绪」文档（内容你熟悉）

## 演示路径（建议）

1. **导入/状态**：展示文档「就绪」与分块预览（可选）
2. **检索工作台**：输入库内问题，展示混合召回与来源卡片
3. **正常问答**：流式回答 + 引用 `[文档#序号]`
4. **拒答**：问一个明显库外问题，展示跳过胡编
5. **（可选）** 切换 SiliconFlow：说明「只云端生成、嵌入仍本地」

## 翻车急救

| 现象 | 立刻做什么 |
|------|------------|
| Ollama 红点 | 启动 Ollama → 检测连接 |
| 无召回 | 换文档原词 / 切关键词模式 |
| 一直拒答 | 确认文档就绪；换强相关问题 |
| 云端失败 | 切回 Ollama 对话，或检查 Key |

详见 [troubleshooting.md](./troubleshooting.md)。
