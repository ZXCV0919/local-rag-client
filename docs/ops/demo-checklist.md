# 演示前 Checklist（约 90–120 秒）

用于产品演示 / 答辩，避免环境翻车。

## 启动前

- [ ] Ollama 已运行；顶栏无依赖警告（或设置页绿点）
- [ ] 已拉取 `nomic-embed-text`；对话模型已拉取（若演示本地生成）
- [ ] ChromaDB 心跳正常（设置 → 数据管理）
- [ ] 可用「导入演示语料」一键装入样例库，或自备 1 个小知识库 + ≥1 份「就绪」文档

## 录屏脚本（90–120 秒）

| 时段 | 画面 |
|------|------|
| 0–15s | 打开应用；健康条正常（或快速展示「未连接 → 连接后消失」） |
| 15–40s | 首页点「导入演示语料」或展示文档「就绪」与导入进度 |
| 40–75s | 对话页提问 → 流式回答 → 点开引用 |
| 75–100s | 上方「排查检索」对照命中片段（强调这是排查工具，不是主入口） |
| 100–120s | 设置：本地嵌入 + 可选 SiliconFlow「只碰生成」 |

## 演示路径（口头版）

1. **导入/状态**：文档「就绪」；大文件时强调勿关窗口
2. **正常问答**：流式回答 + 引用
3. **检索工作台**：核对命中（排查搜错还是答错）
4. **拒答**：问一个明显库外问题
5. **（可选）** 切换 SiliconFlow：说明「只云端生成、嵌入仍本地」

## 翻车急救

| 现象 | 立刻做什么 |
|------|------------|
| 顶栏依赖警告 | 启动 Ollama / 拉取嵌入模型 / 启动 Chroma |
| 无召回 | 换文档原词 / 切关键词模式 |
| 一直拒答 | 确认文档就绪；换强相关问题 |
| 云端失败 | 切回 Ollama 对话，或检查 Key |

详见 [troubleshooting.md](./troubleshooting.md)。
